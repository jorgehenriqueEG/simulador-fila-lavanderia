# Simulador Fila Lavanderia
## Descrição do Problema
Simular o tempo de espera para clientes em uma lavanderia com base na capacidade da máquina e na quantidade de peças.
## Requisitos
- Receber lista de tamanhos de roupas (S, M, G)
- Calcular tempo por tamanho (S=10, M=20, G=30 min)
- Somar tempos e aplicar multa de 5 min se total > 60 min
- Mostrar se o cliente consegue sair antes das 18h
## Exemplo de Uso
Entrada: ["S", "G", "M"]
Saída: Tempo total: 65 min | Multa: 5 min | Sai antes das 18h: False
